# 发布签名证书指纹

# ## 这个文件是「签名一致」的唯一判据
#
# Android 拒绝安装签名不同的更新。密钥一旦丢失或换掉，
# 用户就只能卸载重装——**数据会一起消失，无法恢复**。
#
# ## 密钥必须放在哪里
#
# **绝不能放 %TEMP%**：本项目已经在那里丢过一次密钥。
# 现位置：C:\Users\26315\.android\mistakebook\mistakebook-release.jks
# 另需离线备份一份，换机器时按本文档重建。
#
# 重建时 applicationId 也要一致，否则会被当成另一个 App。
#
# ## 什么时候必须改这个文件
# **仅当**下列情况之一发生：
# 1. 首次创建发布签名（本文档就是为此而设）
# 2. 确认发布密钥永久丢失且无法找回
#    ——此时 applicationId 也要一并更换，否则老用户只能卸载（数据丢失）
#
# 格式固定为**大写冒号分隔**，与 keytool -list -v 输出逐字符相同。
# apksigner 不加冒号（64 字符），两边格式不同，脚本已做归一化。
